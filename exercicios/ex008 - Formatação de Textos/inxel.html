Principais formatações

Negrito / Destaque

Para colocar o negrito no texto, existem duas formas:

a que usa a letra B, mas é uma tag não semântica.

e também tem a tag STRONG. ela também transforma
o texto em negrito e de brinde é uma tag semântica!

Itálico / Ênfase

O italico também tem suas formas semântica e não semântica.

a primeira forma de usar o itálico é assim, com a letra I. mas é não semântica.

e também temos a forma semântica da coisa, usando
a tag EM, que signiica EMPHASIS, do inglês, para dar ênfase.


Tags semânticas trazem maior significado para nossos termos e conteúdos dentro do HTML.

Texto Marcado

Dá também para criar textos marcados usando a tag MARK.

E é possível também alterarmos as cores da marcação.
Mas aí já entramos em CSS.

E também tem como adicionar uma cor para todas as marcações
de texto, com a tag style → background color na HEAD. Dessa forma
eu terei a cor que eu quiser para todas as marcações.

Textos Grande e Pequeno

Vamos fazer textos grandes e textos pequenos

Mas a tag BIG não é mais utilizada dentro da HTML, mas ainda funciona.

Se quiser mudança de tamanho de fonte, arrume na formatação!

Texto Deletado

Os textos deletados usam a TAG DEL hoje em dia.

Texto Inserido

Podemos marcar um texto como inserido para dar uma ênfase e indicar
que ele foi adicionado depois.

Tambem existe com a TAG U, mas ela não tem semântica.

Texto Sobrescrito

Otimo para inserir calculos, exemplo: x2+300-32

Texto Subescrito

Ajuda a colocar numeros ou letras no subescrito, exemplo:H20
